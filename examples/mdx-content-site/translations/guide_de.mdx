# Entwickle eine kleine Routine

{/* mojito-id: guide.intro */}
Eine hilfreiche Routine beginnt so klein, dass sie in einen ganz normalen Tag passt. Wähle einen Moment, den du ohnehin hast, und gib ihm einen kleinen Zweck.

{/* mojito-id: guide.begin.title */}
## Beginne mit fünf Minuten

{/* mojito-id: guide.begin.body */}
Lies beim Frühstück eine Seite, mach dir nach einem Spaziergang eine Notiz oder besprich eine Idee mit einem Freund. Regelmäßigkeit zählt mehr als der Umfang der Aufgabe.
