# 小さな習慣を作る

{/* mojito-id: guide.intro */}
役立つ習慣は、いつもの一日に無理なく収まる小さなことから始まります。普段のちょっとした時間を選び、ささやかな目的を持たせてみましょう。

{/* mojito-id: guide.begin.title */}
## まずは5分から

{/* mojito-id: guide.begin.body */}
朝食のときに1ページ読む、散歩のあとにメモを取る、友人とアイデアについて話す。取り組みの大きさよりも、続けることが大切です。
