Use Mojito's **Insert special** menu for common spaces, punctuation, and direction
marks. For more characters, use your computer's character picker. To type in
another language, select a keyboard layout or input method in your system settings.
An input method editor (IME) helps compose text in languages such as Japanese or
Chinese; a character picker lets you choose individual symbols or emoji.

Click in the translation and place the caret before using a system shortcut.
These shortcuts operate your computer's tools directly; Mojito's menu provides
instructions for opening them.

## macOS

### Open the character picker

Press **Control + Command + Space** to open Character Viewer.
**Fn/Globe + E** is another supported shortcut. [Apple: Mac keyboard shortcuts](https://support.apple.com/en-us/102650)

You can also choose **Edit > Emoji & Symbols** from the application's menu bar.
Search or browse, then click a character to insert it; in the expanded viewer,
double-click the character. [Apple: Use emoji and symbols](https://support.apple.com/guide/mac-help/mchlp1560/mac)

### Switch or add an input language

Press **Control + Space** to return to the last input source you used, or
**Control + Option + Space** for the next source. You can also choose a source
from the **Input menu** in the menu bar.

To add one, open **System Settings > Keyboard**, find **Text Input**, and select
**Edit > +**. Choose the language and input source, then select **Add**.
The Input menu's **Show Keyboard Viewer** displays the selected layout.
[Apple: Write in another language](https://support.apple.com/guide/mac-help/mchlp1406/mac)

## Windows 11

### Open the emoji and symbol picker

Press **Windows + . (period)** while editing text. Choose **Symbols** for
punctuation and other symbols, or choose an emoji. For additional characters,
search for **Character Map** from Start, copy a character, and paste it into your
translation. [Microsoft: Keyboard and text tools](https://support.microsoft.com/en-us/accessibility/windows/use-a-screen-reader-to-explore-and-navigate-different-keyboard-and-text-tools-in-windows)

### Switch or add an input language

Hold **Windows** and press **Space** to cycle through installed keyboards, or
select the input language icon in the taskbar.

To add a language, open **Settings > Time & language > Language & region** and
select **Add a language**. To add a keyboard for an installed language, open its
**… > Language options**, then select **Add a keyboard** under **Keyboards**.
[Microsoft: Language and keyboard settings](https://support.microsoft.com/en-us/windows/hardware/input-devices/manage-the-language-and-keyboard-input-layout-settings-in-windows)

For an IME language such as Japanese, select the installed language first. Then
right-click its **IME options** icon in the taskbar to choose an input mode or
open IME settings. Available modes depend on the language.
[Microsoft: Input methods for East Asian languages](https://support.microsoft.com/en-us/windows/hardware/input-devices/advanced-input-methods-for-east-asian-languages)

System instructions and default shortcuts verified against the linked support
pages on September 4, 2026. Use the system menus if your shortcuts are customized.
